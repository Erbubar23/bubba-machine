Code of conduct

Bubba Machine is a project for making music. We want anyone to be able to take part regardless of experience, background, gender, identity, age, language or way of making music.

What we expect

  • Treat others with respect, also when we disagree.
  • Criticize ideas and code, never people.
  • Remember that many people contribute in their free time and while learning.
  • Help newcomers: there are no silly questions about the FM-1.

What we do not accept

  • Insults, harassment, threats or discriminatory comments.
  • Publishing other people's personal data without their permission.
  • Out-of-place sexual or violent content.
  • Insisting after someone asked you to stop.

How to report

If something makes you uncomfortable, write to the project maintainer in a private message on GitHub (@Erbubar23). Reports are handled discreetly. Anyone who does not respect this code may receive a warning or be blocked from the project.
